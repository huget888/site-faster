site-faster is a faster drop-in for makefun-site 1.0.0: a dependency-free ES module whose run(input) returns exactly the answer makefun-site returns for every case — the output tree of every page, index and tag page, build-report.txt and static file, byte for byte — but with a purpose-built single-pass Markdown parser, templates compiled once and cached, and allocation-light hot paths. On the kit's 3-case practice set it runs about 3.76x faster than the house baseline on CPU time.

## Run it

```sh
node main.ts
```
